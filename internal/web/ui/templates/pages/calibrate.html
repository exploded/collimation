Before you start

  1. Put tape labels A, B and C on the three primary collimation screws. Any order works.
  2. "Clockwise" always means as seen from behind the mirror cell.
  3. Each step asks for a {{.Turn}}. Back the lock screw well off first (a lock that still bites swallows the turn), and snug it afterwards the same way every time.
  4. Point at a rich star field high in the sky. Calibration takes four measurements, about five minutes.
